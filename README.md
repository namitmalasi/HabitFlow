
# HabitFlow – Build Better Habits

HabitFlow is a responsive habit tracker built with React. It helps users build consistent routines, track daily progress, monitor streaks, and understand their habits through visual analytics.

## Features

- **Habit Management** – Create, edit, and delete habits.
- **Daily Check-ins** – Mark habits as completed with one click.
- **Streak Tracking** – Track current and longest completion streaks.
- **Activity Heatmap** – View yearly habit activity in a GitHub-style heatmap.
- **Analytics Dashboard** – Visualize weekly and monthly habit completion.
- **Habit Reminders** – Get in-app reminders for incomplete habits and missed days.
- **Data Backup** – Export and import habit data using JSON files.
- **Persistent Storage** – Keep habits and check-in history saved in the browser.
- **Responsive Design** – Use the application on desktop and mobile devices.

## Tech Stack

- **Frontend:** React, JavaScript, Vite
- **Styling:** Tailwind CSS
- **State Management:** Zustand
- **Charts:** Recharts
- **Icons:** Lucide React
